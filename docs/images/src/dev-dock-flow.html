3
3.install-vnc-core.sh

4
4.install-custom-pkgs.sh
VS Code (runs with --no-sandbox), Firefox, AnyDesk
5
5.install-conda.sh
Miniconda in /opt/conda
6

opens up /root and the scripts for every user
